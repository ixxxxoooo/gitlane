# 0001 读写分路:读用 git2,写用系统 git

日期:2026-11-04 · 状态:已采纳

## 背景

客户端既要在大仓库里快速读取历史、status、diff,又要保证写操作和用户在命令行里的行为完全一致
(凭据助手、钥匙串、hooks、提交签名、`pull.rebase` 等配置)。

## 决定

- **读路径**:git2(libgit2 绑定,vendored 编译,不依赖系统 libgit2)。进程内调用,不用解析文本输出。
- **写路径**:系统 `git` 命令行(`gitcore::Git`)。统一设置 `GIT_TERMINAL_PROMPT=0`(没有终端可输入密码)、
  `GIT_EDITOR=true`(提交信息由我们通过 stdin 提供)、`LC_ALL=C`(错误信息稳定)。
- 部分暂存不直接写索引,而是生成补丁交给 `git apply --cached --recount`。
- gitoxide 暂不使用;主线功能完成后再评估是否替换读路径。

## 影响

- 用户必须安装 git ≥ 2.30;启动时检测并在标签栏提示。
- libgit2 与 git 的细微差异只影响“显示”,不影响“写入”的正确性。
- 每次写操作启动一个进程,单次开销约数毫秒,对交互无感。
